## The entry

A robot vacuum gives its deadpan excuse for missing one spot — it found the
spot, mapped it, circled it twice, and then deliberately left it alone. The
punch lands at the end: the spot turned out to be the cat's favourite napping
patch, and the vacuum's warranty does not cover starting wars.

## How it works

`main.py` (Python standard library only, no dependencies) writes a single
line of at most 200 characters to `/output/entry.txt` — or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set — plus a
best-effort copy next to the script for local inspection.

```sh
python3 main.py
cat entry.txt
```
